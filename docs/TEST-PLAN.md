# Test and handoff / 测试与交接

Version 20261120.10. This public build is compiled only; not flashed or functionally tested. External tests of the private-deployment .9 build passed actual online installation, two separate 20-minute software-continuity runs and reader position recovery. They also found queue-failure cancellation, native-back policy, narrow English button layout and repeated BLE discovery failures. Those results do not establish public-build acceptance or physical smoothness. Device screen images are virtual previews. Preserve existing manuscripts/settings and do not flash C6. Android is not included.

1. Verify ZIP manifest, binary size and SHA-256. Install only the main application BIN using the controller or `/firmware/` on SD; follow ZIP instructions for USB. Confirm the new version and a healthy boot. Record update method, duration and reboot behavior.
2. On mobile, check factory reset at the left and save at the right in Chinese and English, light/dark. Do not actually reset valuable settings for a layout check.
3. With a temporary manuscript, enable loop and header state. Expect `循环次数：0` / `Loop count: 0`, then increasing completed counts. The red dot before playing should visibly alternate bright/dim; countdown, paused, stopped and standby must not show a playing dot.
4. Copy temporary A, queue a copy of B and deletion of C. A new loading item appears next to the visible original. Success follows submission order, with correct placeholder geometry and no duplicates. Inject a failure for only the first A read, then restore successful requests: all already queued B/C jobs must cancel, C must remain, and no later write may replay. Repeat three times, also fail create separately. Newly submitted work may run after the error. Check disconnect/update cancellation, layout switches and search filtering.
5. Required update: use the virtual Demo `/console.html?update=required` first. The modal has only Download and install; Esc, backdrop, cancel and three document-level `teleprompter-app-back` events must not dismiss it. Fail the download or checksum and expect required Retry. A changed device connection invalidates the old target. Same/older versions must not install. Ordinary updates remain dismissible. Test server policy only with an older test device and an isolated manifest; keep the shared release policy false.
6. Do one actual online cross-version installation on the public deployment, including range download, SHA-256 validation, progress, write lock, healthy reboot and page reload. Same version must not reinstall. Separately cover LAN, BLE and SD update paths only when those paths are affected; do not count checking a manifest as a successful OTA.
7. Play a long temporary manuscript for 20 minutes with no other operations, then another 20 minutes with ordinary controller use. Observe physical jitter, stalls, backward jumps, accidental pause/reboot and preview bounce. Keep logs and a short physical screen video. Software position monotonicity does not prove visual smoothness.
8. Measure full HTML load, a small API request, library and cold/warm preview on hotspot and router LAN, with and without internet. Reader font should fall back locally and use cache. Cover duplicate SSIDs with strong/weak APs if possible.
9. Check mobile background/lock, page exit/re-entry, two controllers, BLE reconnect and actual device reboot. Reading state should recover without unintended playback or rewind. Confirm header/footer controls stay editable over LAN and BLE.
10. Restore all changed settings, remove only the temporary manuscripts, and confirm original text, styles, IDs and manual order are intact. Never format SD or reset all configuration as a cleanup step.

Report firmware version, browser/OS, transport, steps, expected vs actual, screenshot/video, console/serial logs and settings restored. Do not include Wi-Fi passwords, tokens, private manuscript text or operator credentials in a public issue.

Additional .10 priorities: 320px English light/dark factory-reset/save buttons remain on one row (labels may wrap inside); repeat fresh BLE discovery/connect/read/disconnect five times in one boot and verify 30-second advertising renewal does not drop an existing two-minute GATT session. At header sizes 12/22/40, fields must remain whole; insufficient space hides entire optional fields and may hide timecode to preserve state. Verify both device and preview. Mixed-load API latency and physical scrolling jitter remain open issues.

Exact metadata restoration note: manual ordering can register previously unassigned `order=-1` entries and change orderEtag while retaining the visible order. Record this normalization separately from manuscript corruption; do not erase SD to force a baseline value. Native regression scripts are optional development tools, not included or required in the firmware ZIP.
